# AH Marketing ভিডিও তৈরি

এই রিপো অ্যাপ (AH Marketing Social Media Automation) এর পাঠানো কাজ থেকে GitHub Actions এ ফ্রিতে তৈরি করে:

- রিল (9:16) আর YouTube/ওয়েবসাইটের জন্য আড়াআড়ি (16:9) ভিডিও, থাম্বনেইলসহ
- সাপ্তাহিক কুইজের ভিডিও
- পোস্টের ছবি (4:5)

অ্যাপ `render` শাখায় `jobs/<id>.json` রাখে আর `render-quiz` ইভেন্ট পাঠায়। তৈরি ফাইল `quiz-<id>-<tag>` নামের artifact এ থাকে, অ্যাপ সেখান থেকে নিয়ে Drive এ রাখে।

প্রতিটা ব্র্যান্ডের জন্য আলাদা রিপো রাখা যায়: অ্যাপের সেটিংসে সেই ব্র্যান্ডের "ভিডিওর GitHub রিপো" আর token দিয়ে "ভিডিও কোড বসান" চাপলে এই কোড সেখানে বসে যায়।

ভিডিও তৈরিতে [Remotion](https://www.remotion.dev) ব্যবহার হয়েছে (ছোট প্রতিষ্ঠানের জন্য ফ্রি লাইসেন্স)।
